# QBR deck outline

A quarterly business review is a decision meeting, not a status report. This skill turns scattered account notes into an outline that always answers the same four questions in the same order.

## Inputs

Ask for what the user has and mark gaps:

| Field | Why it matters |
| --- | --- |
| Account and quarter | Sets the frame |
| Goals agreed last quarter | The baseline for every metric slide |
| Actual metrics (usage, adoption, tickets, revenue) | Evidence for wins and gaps |
| Product changes the client asked for | Separates requests from commitments |
| Open issues and risks | Feeds the risk slide |
| Renewal or expansion date | Sets the ask |
| Attendees and their roles | Decides who the deck is written for |

## Steps

1. **Open with the agreed goals.** Put last quarter's goals and the actual result side by side. Do not add goals that were never agreed.
2. **Choose three wins and three gaps.** Every item needs a number or a dated event. Drop anything that cannot be evidenced.
3. **Build the metric table.** One row per metric: goal, actual, change, status. Use the same unit the client uses.
4. **Name the risks honestly.** For each risk give the cause, the impact if unchanged, and the owner on the user's side.
5. **Write the asks.** Two or three roadmap asks, each tied to a gap or risk on an earlier slide. Say what the client must do, not only what the user will do.
6. **Add a one-line executive summary.** If the reader sees only the first slide, they should still know the quarter's verdict and the ask.
7. **Mark what is missing.** List unknown metrics at the end so they can be filled before the meeting rather than during it.

## Output format

```text
QBR outline: Acme GmbH, Q4 2026

1. Executive summary
   Verdict: adoption up, two integration risks, one expansion ask.
2. Goals vs actuals
   | Goal | Actual | Change | Status |
3. Wins
   1. ... (number or dated event)
4. Gaps
   1. ... (number or dated event)
5. Risks
   1. Cause / impact / owner
6. Roadmap asks
   1. Ask / why now / what the client does
7. Next quarter goals
8. Missing data
```

## Rules

- Keep the slide order above unless the user asks for a different agenda.
- Every win, gap and risk cites a supplied number, date or quote. No vibes.
- Never invent a client commitment or a product delivery date.
- Keep the deck to eight sections; if the user needs more detail, put it in an appendix and say so.
- Match the client's metric names and units rather than translating them into internal jargon.
